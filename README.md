# COLORSLab
A web application that allows users to log in and keep track of colors. This project helps in familiarizing ourselves with the LAMP tech stack in preperation for our Small Project in COP4331C.

The application is hosted on a DigitalOcean Droplet using the LAMP stack which has Linux for its operating system, Apache for the web server, MySQL for its database, and PHP for the backend.
